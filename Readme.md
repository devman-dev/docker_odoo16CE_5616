# Proyecto de Automatización con Docker y Caddy

## Introducción
Odoo 16 CE configurado para que funcione FE ARCA con Reg. 5616



## Instrucciones 

1. Ejecutar up.sh

2. Se instala todo y levanta 

3. Luego para bajarlo, levantarlo o restartearlo es: 

- docker-compose up -d
- docker-compose down 
- docker-compose restar
